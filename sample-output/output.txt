==================================================
COMPARE SINGLY VS DOUBLY
==================================================
Pointers per node      : Singly = 1 (next)          | Doubly = 2 (prev, next)
Memory per node        : Singly = less              | Doubly = more
Traversal              : Singly = forward only      | Doubly = forward and backward
Insert at beginning    : O(1) in both
Insert at end          : Singly O(n) without tail   | Doubly O(1) with tail
Delete from end        : Singly O(n)                | Doubly O(1) with tail
Delete a given node    : Singly needs previous node | Doubly uses prev directly
Reverse                : Singly flips next          | Doubly swaps prev and next
Search / Count / Max   : O(n) in both
Implementation         : Singly = simpler           | Doubly = more pointer updates
